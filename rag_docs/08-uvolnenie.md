# Увольнение (Offboarding)

## Порядок увольнения

### 1. Решение

- Сотрудник подаёт заявление об увольнении (за 2 недели при увольнении по собственному желанию).
- Руководитель и HR обсуждают условия (возможно соглашение сторон).
- Дата увольнения фиксируется в приказе.

### 2. Передача дел (последние 2 недели)

- Сотрудник передаёт дела руководителю / преемнику.
- Закрываются все незавершённые задачи в Jira.
- Передаётся доступ к проектам и репозиториям.

### 3. Последний рабочий день

**До конца дня:**
- Вернуть всё корпоративное оборудование (ноутбук, монитор, пропуск и т.д.).
- IT-отдел проводит инвентаризацию и снимает оборудование с баланса.
- Сдать пропуск в лобби.

**Процедура расчёта:**
- Выплата заработной платы за отработанные дни.
- Компенсация неиспользованного отпуска.
- Выходное пособие (при увольнении по соглашению сторон — по договорённости).

### 4. После увольнения

- Блокировка всех корпоративных аккаунтов в течение **1 рабочего дня** после даты увольнения.
- Отправка трудовой книжки / выписки из СФР.
- Сохранение архива рабочей почты на **30 дней** (по запросу сотрудника).

## Виды увольнения

| Вид | Сроки | Компенсация |
|-----|-------|------------|
| По собственному желанию | 2 недели | Компенсация отпуска |
| По соглашению сторон | По договорённости | По соглашению (минимум 2 оклада) |
| Истечение срока трудового договора | По дате | Компенсация отпуска |
| Сокращение штата | 2 месяца | 2 оклада + компенсация отпуска |

## Чек-лист увольнения

- [ ] Заявление об увольнении / соглашение сторон.
- [ ] Передача дел руководителю.
- [ ] Закрытие задач в Jira.
- [ ] Возврат оборудования (ноутбук, монитор, пропуск).
- [ ] Удаление личных файлов с рабочего ноутбука.
- [ ] Подписание акта приёма-передачи оборудования.
- [ ] Получение расчётного листка.
- [ ] Получение трудовой книжки / выписки из СФР.
