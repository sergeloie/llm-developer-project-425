# Оформление на работу (Onboarding)

## Этапы оформления

### 1. До первого дня (за 1-2 недели)

- HR отправляет письмо с инструкциями по оформлению.
- Сотрудник предоставляет документы:
  - Паспорт (скан).
  - Трудовая книжка (или сведения о стаже из СФР).
  - СНИЛС.
  - ИНН.
  - Диплом об образовании.
  - Медицинская книжка (для определённых должностей).
  - Фотография 3×4 (2 шт.) — для пропуска.

### 2. Первый день

**Утро:**
- Встреча в лобби с HR (9:00).
- Подписание трудового договора.
- Получение корпоративного пропуска.
- Обзор офиса (30 минут).

**День:**
- Получение IT-оборудования (ноутбук, периферия).
- Настройка рабочего места (аккаунты, VPN, почта).
- Знакомство с руководителем и командой.
- Получение плана стажировки (первые 2 недели).

**Вечер:**
- Онбординг-встреча с HR (30 минут): корпоративные правила,benefits, каналы коммуникации.

### 3. Первая неделя

- Знакомство с основными инструментами: Slack, Jira, GitHub, Confluence.
- Знакомство с командой на общем митинге.
- Первые задачи (под руководством наставника).
- Заполнение личной карточки в HR-системе.

### 4. Первые 2 недели (стажировка)

- Ежедневные чек-ины с наставником.
- Знакомство с процессами: 코드-ревью, деплой, релизы.
- Завершение стажировки — собеседование с руководителем.

### 5. Первые 3 месяца (испытательный срок)

- Ежемесячная встреча с руководителем (оценка прогресса).
- По завершении — решение о прохождении испытательного срока.
