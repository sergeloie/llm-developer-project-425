# Удалённая работа

## Виды дистанционной работы

| Тип | Описание | Согласование |
|-----|----------|-------------|
| Постоянная удалёнка | Работа из дома 100% времени | Согласование с руководителем + HR |
| Гибридный формат | 2-3 дня из дома, остальные в офисе | По согласованию с руководителем |
| Временная удалёнка | До 10 рабочих дней подряд | Согласование с руководителем |
| Разовая удалёнка | 1-2 дня, по необходимости | Уведомление руководителя |

## Порядок перехода на удалённую работу

### Постоянная удалёнка

1. Подайте заявление через портал: **HR → Дистанционная работа → Подать заявление**.
2. Приложите согласие руководителя.
3. HR рассмотрит заявление в течение **5 рабочих дней**.
4. Подпишите дополнительное соглашение к трудовому договору.

**Требования:**
- Наличие стабильного интернета (минимум 50 Мбит/с).
- Рабочее место должно соответствовать требованиям охраны труда.
- Обязательно подключение к VPN при работе с корпоративными системами.

### Гибридный формат

1. Согласуйте график с руководителем.
2. Зарегистрируйте график в системе: **HR → Гибридный формат → Настроить график**.
3. Гибридный формат вступает в силу с первого числа следующего месяца.

### Временная удалёнка (до 10 дней)

1. Уведомьте руководителя (письменно или через мессенджер).
2. Зарегистрируйте период: **HR → Временная удалёнка → Зарегистрировать**.
3. Не требует дополнительных соглашений.

## Оборудование для удалённой работы

Компания предоставляет:

- **Ноутбук** (по стандартному набору для должности).
- **Внешний монитор** — по запросу через IT-поддержку (аренда или покупка).
- **Веб-камера и наушники** — по запросу.
- **Компенсация за интернет** — 1 500 ₽/месяц (после подписания соглашения).

Заказ оборудования: **IT → Дополнительное оборудование → Удалённая работа**.

## Режим работы

На удалённой работе сотрудник обязан:

- Быть доступным в рабочее время (10:00–19:00 МСК).
- Отвечать на сообщения в течение **15 минут**.
- Участвовать в статусных митингах (по графику команды).
- Подключаться к VPN при работе с конфиденциальными данными.

## Запрещается

- Работа из кафе / коворкингов без согласования (из-за риска утечки данных).
- Передача корпоративного оборудования третьим лицам.
- Использование личного устройства для работы с конфиденциальными данными (без одобрения IT).
