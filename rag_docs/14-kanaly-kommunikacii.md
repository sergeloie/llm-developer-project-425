# Каналы коммуникации

## Основные каналы

### Slack

Основной инструмент повседневной коммуникации.

| Канал | Назначение |
|-------|-----------|
| #general | Общие объявления компании |
| #dev | Технические вопросы разработки |
| #design | Дизайн-команда |
| #hr | Вопросы к HR (отпуск, benefits, кадры) |
| #it-support | Техническая поддержка, сброс паролей, оборудование |
| #random | Неформальное общение |
| #announcements | Важные объявления от руководства |

**Правила:**
- Используйте треды для обсуждений, чтобы не засорять канал.
- Отвечайте на сообщения в течение **1 рабочего часа**.
- Для экстренных вопросов — напишите в #it-support или позвоните.

### Email (GSuite)

Используется для:

- Формальных письм (HR, бухгалтерия, юристы).
- Уведомлений от систем (Jira, GitHub, Confluence).
- Внешней коммуникации (клиенты, партнёры).

**Адрес:** фамилия.имя@company.ru

### Jira

Управление задачами и проектами:

- Создавайте задачи для любой работы (баги, фичи, технический долг).
- Используйте лейблы и компоненты для фильтрации.
- Регулярно обновляйте статус задач.

### Confluence

Документация и знания:

- Каждый проект имеет пространство в Confluence.
- Документируйте архитектурные решения (ADR).
- Ведите meeting notes и протоколы.

### Wiki

Внутренний справочник:

- Корпоративные правила и регламенты.
- Инструкции по сервисам.
- FAQ.

## Статусные митинги

| Митинг | Участники | Частота | Длительность |
|--------|----------|---------|-------------|
| Daily Standup | Команда проекта | Ежедневно | 15 мин |
| Weekly Sync | Команда + руководитель | Еженедельно | 1 час |
| Sprint Review | Команда + стейкхолдеры | Каждые 2 недели | 1 час |
| Retrospective | Команда | Каждые 2 недели | 45 мин |
| All Hands | Вся компания | Ежемесячно | 1 час |

## Экстренная коммуникация

### Инцидент (авария / взлом / outage)

1. Напишите в Slack: #incidents (или @here в #it-support).
2. Позвоните на горячую линию: 8-800-555-12-34.
3. Не обсуждайте инцидент в публичных каналах.

### Срочные HR-вопросы

- Позвоните HR: внутренний номер 101.
- Напишите в Slack: #hr (для несрочных вопросов).

## Внешняя коммуникация

- С клиентами — только через выделенные каналы (email / Slack-интеграция).
- В соцсетях — по согласованию с маркетингом.
- На конференциях — только после одобрения PR-отдела.
