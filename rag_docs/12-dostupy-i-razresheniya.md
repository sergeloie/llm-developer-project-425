# Доступы и разрешения

## Типы доступов

| Уровень | Описание | Кто выдаёт |
|---------|----------|-----------|
| Базовый | Корпоративная почта, Slack, Jira, Confluence | Автоматически при трудоустройстве |
| Проектный | Доступ к репозиториям и базам данных проекта | Руководитель проекта |
| Привилегированный | Доступ к продакшн-системам, AWS/Yandex Cloud | IT-директор |
| Административный | Полный доступ к инфраструктуре | CTO |

## Запрос доступа

### Базовый доступ

Назначается автоматически при приёме на работу. Включает:

- Корпоративная почта (GSuite).
- Slack (каналы по должности).
- Jira (просмотр и создание задач).
- Confluence (чтение и редактирование в自己的 пространстве).

### Проектный доступ

1. Согласуйте с руководителем проекта.
2. Подайте заявку: **IT → Доступы → Проектный доступ**.
3. Укажите:
   - Проект (название / ключ в Jira).
   - Тип доступа (репозиторий, база данных, API).
   - Уровень (read / write / admin).
4. Срок выдачи: **1 рабочий день**.

### Привилегированный доступ

1. Подайте заявку через руководителя.
2. Руководитель направляет заявку IT-директору.
3. IT-директор утверждает и выдаёт доступ.
4. Срок: **до 3 рабочих дней**.

**Важно:** Привилегированный доступ подлежит ревизии каждые **3 месяца**.

## Управление доступами

### Просмотр текущих доступов

- **Почта и SSO:** portal.company.ru → IT → Мои доступы.
- **GitHub:** Settings → Organizations → Выберите организацию → Members.
- **AWS/Yandex Cloud:** Портал云-провайдера → IAM → Users.

### Отзыв доступа

Доступ отзывается автоматически:

- При увольнении — все доступы блокируются в день увольнения.
- При смене проекта — доступы к старому проекту отзываются в течение **3 рабочих дней**.
- По запросу руководителя — в течение **1 рабочего дня**.

## Согласование доступов

Для доступов к конфиденциальным данным требуется:

- Согласие руководителя проекта.
- Согласие руководителя службы безопасности (для продакшн-данных).
- Подписание дополнительного соглашения о неразглашении (если не подписано ранее).

## Экстренный доступ

В случае инцидента (авария, взлом, потеря данных):

1. Позвоните на горячую линию IT: 8-800-555-12-34.
2. Доступ будет выдан немедленно без стандартного согласования.
3. После инцидента — оформление retrospective (в течение 24 часов).
