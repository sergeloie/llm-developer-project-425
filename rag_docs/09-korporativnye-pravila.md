# Корпоративные правила

## Рабочее время

- **Начало рабочего дня:** 10:00 МСК.
- **Окончание рабочего дня:** 19:00 МСК.
- **Перерыв на обед:** 13:00–14:00 (1 час, не входит в рабочее время).
- **Гибкий график:** допускается отклонение до ±2 часов от стандартного времени при согласовании с руководителем.

## Дресс-код

- **Бизнес-кэжуал:** чистая, опрятная одежда, без спортивных костюмов и шлёпанцев.
- **Для клиентских встреч:** деловой стиль.
- **Пятница:** неформальный стиль (jeans + футболка допускаются).

## Использование корпоративных ресурсов

### Разрешено

- Работа с корпоративными системами и инструментами.
- Использование корпоративной почты для рабочих задач.
- Использование лицензионного ПО, установленного IT-отделом.

### Запрещено

- Установка стороннего ПО без согласования с IT.
- Использование корпоративных ресурсов в личных целях (кроме кратковременных).
- Передача учётных данных третьим лицам.
- Работа с конфиденциальными данными на личных устройствах (без одобрения IT).

## Конфиденциальность

- Все сотрудники подписывают NDA (соглашение о неразглашении) при трудоустройстве.
- Конфиденциальная информация включает: код, базы данных, клиентские данные, бизнес-планы, финансовые данные.
- Нарушение конфиденциальности влечёт дисциплинарное взыскание вплоть до увольнения.

## Безопасность

- **VPN обязателен** при удалённой работе и доступе к корпоративным системам.
- **2FA обязательна** для всех внешних сервисов (GitHub, AWS, Yandex Cloud).
- **НеANCEC** корпоративные пароли, не используйте один пароль для нескольких сервисов.
- Сообщайте IT о любых подозрительных письмах или инцидентах.

## Корпоративная коммуникация

| Канал | Назначение |
|-------|-----------|
| Slack | Основной канал коммуникации, экстренные вопросы |
| Email | Формальные письма, уведомления от HR |
| Confluence | Документация, знания, регламенты |
| Jira | Управление задачами, отслеживание проектов |
| Wiki | Внутренний справочник |

### Правила общения в Slack

- Используйте каналы по назначению (#dev, #hr, #general и т.д.).
- Не отправляйте личные сообщения по рабочим вопросам (используйте треды).
- Отвечайте на сообщения в течение **1 рабочего часа** (или поставьте реакцию).

## Дисциплинарные взыскания

| Нарушение | Взыскание |
|-----------|----------|
| Опоздание (до 15 мин) | Устное замечание |
| Опоздание (свыше 15 мин) | Письменное предупреждение |
| Прогул без уважительной причины | Выговор |
| Нарушение конфиденциальности | Выговор / увольнение |
| Повторное нарушение | Увольнение |
