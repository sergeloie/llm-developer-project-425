# Сброс и восстановление пароля

## Корпоративная учётная запись (Active Directory / GSuite)

### Самостоятельный сброс

Если вы ранее настроили восстановление учётной записи:

1. Перейдите на страницу **reset.company.ru**.
2. Введите корпоративный email.
3. Выберите способ подтверждения (SMS на привязанный номер или backup-код).
4. Введите новый пароль.

**Требования к паролю:**
- Минимум 12 символов.
- Минимум 1 заглавная буква, 1 строчная, 1 цифра, 1 спецсимвол.
- Нельзя использовать последние 10 паролей.
- Срок действия пароля — 90 дней.

### Сброс через IT-поддержку

Если самостоятельный сброс невозможен:

1. Подайте заявку: **IT → Пароль → Сброс учётной записи**.
2. Укажите логин и причину сброса.
3. IT-отдел свяжется с вами для верификации личности (внутренний звонок).
4. Пароль будет сброшен в течение **1 рабочего часа**.
5. Новый пароль придёт на личную почту (не корпоративную).

**Важно:** После сброса необходимо сменить пароль при первом входе.

## Двухфакторная аутентификация (2FA)

### Настройка 2FA

1. Откройте приложение Google Authenticator / Authy на телефоне.
2. Отсканируйте QR-код на странице **security.company.ru → 2FA → Настроить**.
3. Сохраните backup-коды в безопасном месте.

### Восстановление доступа при потере телефона

1. Подайте заявку: **IT → Пароль → Восстановление 2FA**.
2. Предоставьте backup-код или ответьте на контрольные вопросы.
3. 2FA будет сброшена в течение **30 минут**.

## Блокировка учётной записи

Учётная запись блокируется при:

- 5 неудачных попытках ввода пароля.
- По запросу руководителя или сотрудника.
- При увольнении (блокировка в день увольнения).

Для разблокировки — заявка через IT-поддержку с указанием причины.
