# Запрос программного обеспечения

## Порядок запроса ПО

### 1. Лицензионное ПО (штатное)

Стандартное ПО устанавливается IT-отделом при настройке рабочего места. Включает:

- Операционная система (macOS / Windows / Linux).
- Пакет Microsoft Office / Google Workspace.
- IDE (JetBrains, VS Code).
- Браузер (Chrome / Firefox).
- Клиент электронной почты.
- Slack, Jira, Confluence.

### 2. Дополнительное ПО (по запросу)

Для установки дополнительного ПО:

1. Подайте заявку: **IT → ПО → Запрос на установку**.
2. Укажите:
   - Название и версию ПО.
   - Цель использования (какую задачу решает).
   - Срок использования (временно / постоянно).
3. IT проверит лицензионную доступность и безопасность.
4. Срок установки: **1–3 рабочих дня**.

### 3. Лицензии (покупка)

Если необходимого ПО нет в корпоративном каталоге:

1. Подайте заявку с обоснованием бизнес-потребности.
2. Руководитель согласует бюджет.
3. IT-директор утверждает покупку.
4. Срок: **до 2 недель** (включая согласование и закупку).

## Категории ПО

| Категория | Примеры | Порядок получения |
|-----------|---------|------------------|
| Разработка | IDE, плагины, DevOps-инструменты | По запросу через IT |
| Дизайн | Figma, Adobe CC, Sketch | По запросу через IT |
| Аналитика | Tableau, Power BI, Excel (расширенный) | По запросу через IT |
| Коммуникация | Zoom, Slack, Microsoft Teams | Штатное ПО |
| Безопасность | VPN-клиент, антивирус | Штатное ПО |

## Самостоятельная установка

Самостоятельная установка ПО **запрещена** без согласования с IT-отделом.

Исключения:
- Расширения браузера (из одобренного списка: portal.company.ru → IT → Безопасные расширения).
- Пакеты npm / pip (для разработчиков, после одобрения IT).

**Почему запрещено:** Риск нарушения лицензий, уязвимостей безопасности, конфликтов с корпоративными системами.

## Обновления ПО

- Критические обновления безопасности — обязательны, в течение **48 часов** после объявления.
- Функциональные обновления — по согласованию с IT.
- Откат обновления — по запросу через IT-поддержку.
